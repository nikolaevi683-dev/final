Как считается оценка

Стратегия «отбой от зоны»: направление задаёт тренд D / W, вход ищем на 4H там, где совпало несколько факторов, и только после подтверждения. Лучший вход — коррекция по тренду, импульс не догоняем.

  • Контекст · 30 — сделка по тренду D / W (до 14), фаза рынка (до 8), нанесены уровни и найден POC (по 4).
  • Зона · 30 — по 5 за каждый совпавший фактор: POC, VAH / VAL, узел объёма, отбойные бары, Фибоначчи; ещё 5, если цена уже в зоне.
  • Подтверждение · 20 — отбойный бар или паттерн (10) и всплеск объёма (10).
  • Риск · 20 — прибыль к риску от 1 : 2 (до 10), потеря в пределах порога (6), стоп покрыт деньгами (4).

«Не входить» ставится при любом жёстком нарушении: нет зоны или подтверждения, сделка против тренда без причины, не хватает денег до стопа. Оценка помогает держать дисциплину, прогнозом она не является.

    Не привязан

    Токен хранится в зашифрованном виде на сервере и нигде не показывается повторно

    Безопасность данных

    Сделки хранятся на серверах Supabase и защищены правилами доступа (RLS): каждый пользователь видит только свои данные. Токены Т-Инвестиций дополнительно шифруются AES-GCM и никогда не передаются открытым текстом.

    Облачное хранилище

    Данные сделок синхронизируются с вашим аккаунтом в облаке. При смене браузера или устройства просто войдите по email — вся история загрузится автоматически.

    Как работает синхронизация

    Токен Т-Инвестиций используется только для получения истории ваших сделок. Приложение НЕ совершает операции от вашего имени. Синхронизация происходит по вашему запросу.

    Отказ от ответственности

    Приложение предназначено только для учета и анализа сделок. Мы не даем инвестиционные советы и не несем ответственность за ваши торговые решения и убытки.

    Расчет статистики

    Win Rate = (Прибыльные сделки / Всего сделок) × 100%. Все расчеты происходят локально на вашем устройстве. Профит пересчитывается в выбранную валюту по текущему курсу (источник — open.er-api.com), а не по курсу на дату сделки.

    Темы оформления

    Выбранная тема сохраняется в браузере. Переключение между темной и светлой темой не влияет на данные — только на внешний вид приложения.

    Удаление данных

    Вы можете удалять сделки прямо из приложения. При выходе из аккаунта данные остаются на сервере. Для полного удаления свяжитесь с поддержкой.

    Обновления

    Приложение использует облачные данные, поэтому обновления загружаются автоматически без необходимости переустановки. Ваши данные всегда актуальны.

    Советы по использованию

    • Регулярно проверяйте статистику для анализа своей торговли
    • Добавляйте комментарии к сделкам для лучшего анализа
    • Используйте фильтры по периодам для отслеживания прогресса
    • Сохраняйте токен Т-Инвестиций в безопасности

    Удалить синхронизированные сделки?

    Это действие необратимо! Все сделки, синхронизированные из Т-Инвестиций, будут удалены из приложения.

    Рекомендуем:

    • Сделки, добавленные вручную, не затрагиваются
    • Сделки останутся на счете Т-Инвестиций, удалятся только из приложения
    • После удаления сможете синхронизировать снова
